Projetos.

Catálogo de Filmes

HTML · CSS · JavaScript · Node.js · Express · MySQL · TMDB

Desenvolvi um catálogo colaborativo de filmes que permite cadastrar, buscar e consultar títulos. Durante o cadastro, o usuário escolhe o filme e preenche um formulário; a aplicação utiliza a API do TMDB para buscar automaticamente informações e pôsteres, integrando esses dados ao sistema. O gerenciamento dos filmes é feito com Node.js, Express e MySQL.
