02 / QUEM SOU

Sobre.

COMO CHEGUEI AQUI

Estou fazendo a transição para a área de tecnologia, vindo de outras áreas.

Sou estudante de Engenharia de Software. Antes de direcionar minha carreira para a tecnologia, trabalhei na área administrativa e em ambiente hospitalar.

Aprendo principalmente construindo. Meus projetos pessoais são o lugar onde aplico o que estudo: interface, consumo de API, back-end, banco de dados e versionamento com Git e GitHub.

Dessas experiências anteriores, levo o hábito de conferir o que faço, organizar prioridades e me comunicar com clareza. Isso faz diferença também no código e no trabalho em equipe.

Ainda não tenho experiência profissional em tecnologia, e é isso que procuro: uma primeira oportunidade, em estágio ou vaga júnior, para aprender na prática e contribuir com uma equipe. Tenho interesse em desenvolvimento, QA e testes, suporte de TI e áreas relacionadas.

  • HTML · CSS · JavaScript · React
  • Node.js · Express
  • MySQL
  • APIs · Git · GitHub
