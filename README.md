# Portfólio | Estudante de Engenharia de Software

Portfólio pessoal desenvolvido com dois objetivos:

- Apresentar minha trajetória na Engenharia de Software, meus conhecimentos em tecnologia e os projetos que venho desenvolvendo ao longo da minha jornada de aprendizado.
- Colocar em prática os conhecimentos adquiridos na disciplina de Introdução ao Desenvolvimento de Sistemas Web, do primeiro semestre de Engenharia de Software da UNIASSELVI, a partir de uma atividade proposta na última aula.

## Sobre o projeto

O portfólio reúne minha apresentação pessoal, trajetória profissional, métodos de aprendizado, projetos práticos e tecnologias que fazem parte dos meus estudos.

A identidade visual foi pensada para transmitir um pouco da minha personalidade e das minhas preferências estéticas, com uma proposta voltada ao universo da tecnologia e do desenvolvimento de software. A combinação de tons escuros com detalhes em chartreuse, a tipografia e os elementos visuais foram escolhas feitas para construir uma apresentação com a qual me identifico.

Entre os recursos implementados estão:

- Navegação com indicação da seção ativa.
- Indicador de progresso de leitura.
- Barra de navegação compactada durante a rolagem.
- Animações de entrada e revelação de elementos.
- Respeito à preferência por movimento reduzido.
- Recursos de acessibilidade e navegação.

## Projetos em destaque

## Como executar localmente

O portfólio foi desenvolvido com HTML, CSS e JavaScript puro, sem necessidade de instalação de dependências.

1. Clone o repositório:

```bash
git clone https://github.com/eduardasouzar-dev/portfolio.git
```

2. Entre na pasta do projeto:

```bash
cd portfolio
```

3. Abra o arquivo `index.html` no navegador ou utilize a extensão Live Server no Visual Studio Code.
